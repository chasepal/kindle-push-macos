# 评论区分享文案

看了乔木的分享，顺手做了个 Mac 端「Kindle 推送」小工具：把 Obsidian / 本地 Markdown 拖进去，自动转成 EPUB，再通过 Wi-Fi 发到 Kindle。支持图片、表格、代码、提示块和嵌入笔记，换网络可重新寻找设备，发送后会校验文件。首次插线配对后，日常不用终端或 AI。已开源，感谢乔木的启发！需要已越狱并安装 KOReader。

https://github.com/chasepal/kindle-push-macos
